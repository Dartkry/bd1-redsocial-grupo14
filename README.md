# Proyecto: Red Social Pascualina - Modelo Lógico

**Integrantes del equipo:**
* Daniel Grisales Lopera

**Breve descripción del caso:**
Este proyecto consiste en el diseño del modelo lógico de una base de datos para la "Red Social Pascualina". El objetivo es crear una plataforma que mejore la comunicación e interacción entre los estudiantes, permitiendo la creación de perfiles, la publicación de actualizaciones, y la formación de grupos de estudio y eventos. Se aplicó el proceso de normalización (1FN, 2FN y 3FN) para garantizar la integridad referencial y optimizar la estructura de los datos.
